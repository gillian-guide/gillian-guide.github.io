# [Various Fixes](<https://gtaforums.com/topic/975211-various-fixes/>)

This project aims to fix or improve a large amount of **map issues and textures**. You can see the changelog on the [GTAForums page](<https://gtaforums.com/topic/975211-various-fixes/>).

---

## Installation

1. Make sure you have installed [FusionFix](<https://gillian-guide.github.io/essential-modding/fusionfix/index.md>).
2. Go to the [Google Drive folder](<https://drive.google.com/drive/folders/1nLq3uiw1XFW5lrIwdSLuk2ZhpEWzdLw0>).
3. Download the `Installation through Fusion Overloader.rar` archive.
4. Extract the <mark>update</mark> folder (not it's contents) into the game folder. Replace files if prompted.

   - You can also install some extras from the `Optional Content.rar` archive. Use the <mark>Installation through Fusion Overloader</mark> folder and do the same with the contents as step 4.
