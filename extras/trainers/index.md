# Trainers

Trainers are essentially modmenus that add a lot of fun and useful options. They're also a better alternative to the very limited amount of [cheatcodes](<https://gta.fandom.com/wiki/Cheats_in_GTA_IV>) the game offers. You may want one for [multiplayer](<https://gillian-guide.github.io/extras/multiplayer/index.md>), but make sure your client/server allows them first.

> [!WARNING]
>
> Both trainers require [Ultimate ASI Loader](<https://gillian-guide.github.io/resources/mod-dependencies/#ultimate-asi-loader>).
>
> Also please pick one - don't install both at once.

---

## [ZMenuIV](<https://zolika1351.pages.dev/mods/ivmenu>)

> [!WARNING]
>
> **Compatibility**
>
> This trainer is not compatible with the Complete Edition.

The most powerful and full-fledged trainer for GTA IV. Also includes a Chaos mod with streamer support, and features as absurd as GoldSrc physics.

### Installation

1. Go to [Zolika1351's Zone](<https://zolika1351.pages.dev/mods/ivmenu>).
2. Scroll to the bottom of the page and download the latest version.
3. Extract `ZMenuIV_vx.zip` into the game folder

   - Do not extract `asi loader if not using xliveless`, `for developers`, `old version (has VR support)`, `parachute support(all into game folder)`. Read the `readme.txt` for details on these folders.

### Usage

The default hotkeys are:

- <kbd class="key-f7">F7</kbd> to toggle menu.
- <kbd class="key-num8">Num 8</kbd>, <kbd class="key-num2">Num 2</kbd>, <kbd class="key-num4">Num 4</kbd>, <kbd class="key-num6">Num 6</kbd> for navigation, <kbd class="key-num5">Num 5</kbd> to accept, <kbd class="key-num0">Num 0</kbd> to go back.
- <kbd class="key-right-control">Right Ctrl</kbd>\+<kbd class="key-num1">Num 1</kbd> to fix the car.
- <kbd class="key-right-control">Right Ctrl</kbd>\+<kbd class="key-num2">Num 2</kbd> to flip the car.
- <kbd class="key-bracket-right">]</kbd> (hold) to speed the car up.
- <kbd class="key-f6">F6</kbd> for Airbreak (noclip).
- <kbd class="key-0">0</kbd> for Always God Mode.
- <kbd class="key-bracket-left">[</kbd> for Never Wanted.
- <kbd class="key-semicolon">;</kbd> for Unlimited Ammo.
- <kbd class="key-equal">=</kbd> for Collision.
- <kbd class="key-minus">-</kbd> for Resurrect.
- <kbd class="key-m">M</kbd> for Ragdoll.

You can add your own custom keybinds that can combine multiple options together. To do so, enable `Custom Keybind Creator` in `Trainer Settings`, highlight the desired option and press <kbd class="key-left-control">Left Ctrl</kbd>\+<kbd class="key-enter">Enter</kbd> to set the keybind up.

Edit the `[Keybinds]` section in `ZMenuIV.ini` to change existing keybinds.

> [!TIP]
>
> **Setting up Numpad-less keybinds**
>
> Not everyone has a Numpad, I get it, 80% (and less) keyboards are cool and comfortable. Open `ZMenuIV.ini` and locate these lines:
>
> ```ini
> [Keybinds]
> AirbreakUp=87
> AirbreakDn=83
> AirbreakForward=104
> AirbreakBack=98
> AirbreakLeft=100
> AirbreakRight=102
> MenuUp=104
> MenuDn=98
> MenuLeft=100
> MenuRight=102
> MenuEnter=101
> MenuBack=96
> ```
>
> and change them to:
>
> ```ini
> [Keybinds]
> AirbreakUp=32
> AirbreakDn=160
> AirbreakForward=87
> AirbreakBack=83
> AirbreakLeft=65
> AirbreakRight=68
> MenuUp=73
> MenuDn=75
> MenuLeft=74
> MenuRight=76
> MenuEnter=13
> MenuBack=220
> ```
>
> Which will be:
>
> - <kbd class="key-i">I</kbd><kbd class="key-j">J</kbd><kbd class="key-k">K</kbd><kbd class="key-l">L</kbd> for navigation. <kbd class="key-enter">Enter</kbd> to accept, <kbd class="key-backslash">\</kbd> to go back.
> - <kbd class="key-w">W</kbd><kbd class="key-a">A</kbd><kbd class="key-s">S</kbd><kbd class="key-d">D</kbd> for horizontal airbreak control, <kbd class="key-space">Space</kbd> for going up and <kbd class="key-left-shift">Left Shift</kbd> for going down.

## [Liberty's Legacy](<https://gtaforums.com/topic/973091-gta-iv-12043-libertys-legacy-trainer/>)

> [!WARNING]
>
> **Compatibility**
>
> This trainer is compatible with the Complete Edition, as well as patches 1.0.8.0 and 1.0.7.0.

This trainer is not as powerful as ZMenuIV, but still offers a lot of useful features. It's also the only one you can use with the Complete Edition, anyway. It's also compatible with controllers.

### Installation

1. Install [ScriptHookDotNet](<https://gillian-guide.github.io/resources/mod-dependencies/#scripthookdotnet>) if you hadn't done so yourself outside of the guide.
2. Go to the [GTAForums page](<https://gtaforums.com/topic/973091-gta-iv-12043-libertys-legacy-trainer/>).
3. Download the latest version.
4. Extract the `Liberty's Legacy Trainer xxx.zip` archive into the game folder.

### Usage

The default hotkeys on keyboard&amp;mouse are:

- <kbd class="key-f11">F11</kbd> to toggle menu.
- Arrow keys for navigation, <kbd class="key-enter">Enter</kbd> to accept, <kbd class="key-backspace">Backspace</kbd> to go back.

The controller binds ones are:

- RB+X or R1+Square on controllers.
- D-Pad for navigation, A or Cross to accept, B or Circle to go back.

Additional key bindings can be set by highlighting the desired option, pressing <kbd class="key-left-control">Left Ctrl</kbd>\+<kbd class="key-enter">Enter</kbd> and pressing the key you want to bind.
